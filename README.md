# Trade English — رحلة التاجر

برنامج Windows لتعلّم الإنجليزية المستخدمة في تجارة الأغذية والحلويات والتوريد، بواجهة عربية وخط ثمانية.

## ملف التثبيت

افتح `Installer/TradeEnglish-Setup.exe` ثم اضغط تثبيت البرنامج. الحزمة مخصصة لـ Windows x64، وتضم .NET 10.0.10 والصوتيات للعمل دون تنزيلات إضافية. يثبّت البرنامج لحساب المستخدم في `%LOCALAPPDATA%/Programs/TradeEnglish` ويضيف اختصارًا إلى سطح المكتب وقائمة ابدأ. التقدّم محفوظ في موقعه السابق.

## التشغيل اليومي

اضغط مرتين على **Start-TradeEnglish.cmd**، أو افتح **Program/TradeEnglish.exe**.
تحتاج نسخة التشغيل إلى .NET Desktop Runtime 10، المثبّت بالفعل على الجهاز المستخدم لتجهيز المشروع.
احتفظ بمجلد Program كاملاً؛ مجلد Assets يحتوي المقاطع الصوتية.

## ترتيب المشروع

| المسار | الاستخدام |
|---|---|
| Program | النسخة الحالية الجاهزة للاستخدام، مع الأصوات |
| Source | ملفات C# والمنهج والخطوط والأصوات اللازمة للبناء |
| Archive | الإصدارات القديمة وحزم ZIP وأدوات التوليد والتطوير السابقة |
| Start-TradeEnglish.cmd | تشغيل البرنامج بنقرة مزدوجة |
| Build.ps1 | بناء نسخة جديدة في Build/TradeEnglish دون تعديل النسخة المستخدمة |

## المحتوى الحالي

- 48 درسًا، و288 جملة ثنائية اللغة، و8 حوارات من ثلاث خطوات.
- اختيار المعنى، ترتيب الكلمات، كتابة واستماع، تسجيل للمقارنة الذاتية، ومراجعة متباعدة.
- 1,997 ملف MP3: ستة أصوات تغطي 312 جملة لكل صوت، وصوت إضافي يغطي 125 جملة.
- اختر «عشوائي» من إعدادات الصوت للتبديل بين الأصوات المتاحة لكل جملة.
- الصوت الثامن لا يحتوي مقاطع؛ يُستبعد تلقائيًا من التشغيل العشوائي.
- إعادة الجملة ببطء تحتفظ بالصوت نفسه.

الأصوات المحفوظة تعمل دون إنترنت أو مفتاح API. اكتُفي بالمقاطع الموجودة؛ لا حاجة إلى تشغيل مولّد الأصوات أو شراء رصيد.
إعدادات الربط السحابي القديمة تبقى اختيارية؛ استخدم المقاطع المضمّنة للتعلّم دون استهلاك رصيد.

## حفظ التقدّم

يُحفظ التقدّم خارج مجلد المشروع في:
`%LOCALAPPDATA%/TradeEnglish/progress-v2.json`

لم يُنقل هذا الملف أو يُعدّل أثناء ترتيب المشروع. لا ترفعه إلى GitHub.

## التطوير

يلزم Windows و.NET SDK 10. من PowerShell داخل المجلد:

```powershell
.\Build.ps1
```

الفحص البرمجي للنسخة الحالية:

```powershell
$p = Start-Process .\Program\TradeEnglish.exe -ArgumentList '--self-test' -Wait -PassThru
$p.ExitCode
Get-Content .\Program\test-results.txt -Tail 1
```

الفحوص تتضمن الصوت المحلي، فتح MP3، سلامة المحتوى، التقدّم والمراجعة واختيار الصوت.
لا تُعد بديلًا عن الاستماع البشري لكل مقطع أو شهادة لمستوى اللغة.

## الأرشيف والرفع

Archive نسخة تاريخية محفوظة كما هي؛ أدواته قد تشير إلى مسارات قديمة ولا تُستخدم لتشغيل البرنامج الحالي.
